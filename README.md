# Prompts

Prompts and instruction sets for AI-assisted research, shared for anyone to use and adapt. Each one is plain Markdown. Copy it into an AI agent (Claude Code, ChatGPT, or any agent that can read and write files), or adapt it first.

## Family history

| Prompt | What it does |
|---|---|
| [Build your own family history with AI](family-history/build-your-own-family-history-with-ai.md) | Interviews you about your family, sets up an Obsidian vault tracked with Git, works to academic genealogy standards, and can publish the result as a website with Quartz. Works for any family, from any country. |
| [Train a handwriting model for your parish registers](family-history/train-a-handwriting-model-for-your-parish-registers.md) | Build, measure and publish an open handwriting-recognition model for one archive's old registers, with two AI models making and checking the training data. Work in progress. |
| [Handwriting-model tools](family-history/handwriting-tools/) | The Python scripts for each step: rendering, line cutting, blind-reading sheets, consensus, training data, fine-tuning and scoring. |
| [Vault and website tools](family-history/tools/) | The Python scripts behind the prompt's generated views and website, with one settings file to edit and a made-up example vault to try them on. |
| [How to translate open books and articles](family-history/translate-open-books-and-articles.md) | Side-by-side translations of public-domain and openly licensed texts that keep the original's structure, with the licence checked first and every uncertainty noted. |

They come from the research behind [genealogy.ramsei.ai](https://genealogy.ramsei.ai), part of [ramsei](https://ramsei.ai).
